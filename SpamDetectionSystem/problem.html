1. Problem Statement

With the increasing number of unwanted emails, users face security risks and inbox clutter. The goal of this project is to develop an Email Spam Detection System that automatically classifies emails as “Spam” or “Safe”, helping users filter malicious or unwanted messages efficiently..

Fact: Over 45% of global emails are spam, leading to data breaches and loss of productivity.
